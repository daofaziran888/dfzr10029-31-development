# 数据分析实验与数据应用服务平台

面向指标口径管理、分析实验设计、OLAP查询、数据看板构建与数据API发布的数据应用平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 导出版本固化

数据导出模块在原导出任务时间线之外，提供把数据集快照固化为可复核导出版本的能力，
解决“审计人员收到交付包后源表继续变化、无法复算包内行数或确认数据版本”的问题：

- **输入**：数据集快照（`snapshot` 模块主记录）与交付范围（勾选快照或上传交付范围 CSV）。
- **一次固化**：发起导出批次时读取现有快照记录，按交付范围固化导出版本清单，
  批次号、行数指纹（清单规范化内容的 SHA-256）与源快照标识随批次一次锁定，
  源表之后变化不会改变已固化批次的指纹与内容。
- **处理边界**：只允许“启动时固化”；批次启动后源表仍在变化时，按完成时快照固化会落到
  不同批次内容，该时点在服务端直接拒绝。同一交付范围并发提交通过锁与幂等键保证
  唯一有效批次。
- **归档输入**：文件上传的原始交付范围字节随批次保存，下载固化包（zip）时同步保留
  来源文件，包内还包含 `导出版本清单.csv` 与 `批次说明.json`。
- **复核**：`/api/export/batches/{批次号}/verify` 将导出版本清单与快照主版本逐项核对，
  返回字段级差异、缺失与新增记录；下载入口只返回状态为“已固化”的批次包。
- **页面确认**：导出页按导出批次号、行数指纹、源快照标识三项一致确认，
  可按交付范围发起批次、查看指纹、查询清单、核对主版本并下载固化包。

主要接口（前缀 `/api/export`）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/batches` | 查询导出批次（支持批次号/交付范围/源快照标识关键字） |
| POST | `/batches` | 按交付范围（快照编号列表）固化批次 |
| POST | `/batches/upload` | 上传交付范围 CSV 固化批次，来源文件随包归档 |
| POST | `/batches/from-text` | 文本方式提交交付范围（与上传同解析口径） |
| GET | `/batches/{批次号}/manifests` | 查询导出版本清单 |
| GET | `/batches/{批次号}/verify` | 清单与主版本逐项核对 |
| GET | `/batches/{批次号}/download` | 下载已固化的导出版本包（zip） |
| GET | `/snapshots/options` | 跨模块读取数据集快照与允许的固化时点 |
